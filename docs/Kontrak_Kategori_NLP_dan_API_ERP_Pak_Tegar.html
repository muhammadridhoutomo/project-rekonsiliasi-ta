DAFTAR KATEGORI NLP & USULAN TREATMENT POSTING API ERP

Proyek Tugas Akhir Sistem Rekonsiliasi Keuangan (SIREKON) — Tim ITS (Abror, Mario, Arya) · Tindak Lanjut Arahan Pak Deptha

Sesuai arahan Pak Deptha pada pertemuan 23 November 2026, berikut kami sampaikan daftar lengkap 21 kategori NLP yang diregistrasikan pada sistem SIREKON beserta usulan pemetaan API & treatment posting balik ke ERP Avolut untuk diselaraskan bersama Pak Tegar.

1. Ringkasan 5 Pola Treatment Posting ke ERP

  1. Customer (RECEIVABLE_CUSTOMER): Lookup API Business Partner (Customer) + Open Invoice AR → Push Incoming Payment.
  2. Vendor (PAYABLE_VENDOR): Lookup API Business Partner (Vendor) + Open Invoice AP → Push Outgoing Payment.
  3. Intercompany / Transfer Internal (INTERNAL_TRANSFER, CASH_DEPOSIT, LOAN): Mohon konfirmasi apakah tersedia endpoint Intercompany/Bank Transfer atau tetap menggunakan Incoming/Outgoing Payment melawan Charge perantara.
  4. Kas Kecil / Reimburse (PETTY_CASH): Mohon konfirmasi apakah lookup ke Business Partner (Employee) atau langsung menggunakan Charge kas kecil.
  5. Biaya & Pendapatan Langsung (15 kategori lainnya): Lookup API Charges berdasarkan kode akun CoA → Push Outgoing Payment (Debit) atau Incoming Payment (Kredit).

3. Kebutuhan Teknis Integrasi API Sandbox ERP (untuk Diskusi dengan Pak Tegar)

  • Kredensial Sandbox: Base URL API Sandbox ERP Avolut serta API Key / Token otentikasi.
  • Endpoint GET (Lookup): Business Partner (Customer, Vendor, Employee), Open Invoice (AR/AP), Daftar Charges + pemetaan ke kode akun CoA (khususnya untuk BANK_CHARGE dan BANK_INTEREST).
  • Endpoint POST (Push): Dokumentasi payload untuk Incoming Payment, Outgoing Payment, serta Intercompany/Bank Transfer (jika terpisah).
